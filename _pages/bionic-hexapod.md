## Overview

This project focuses on the development of a bionic hexapod robot for agricultural field scouting. I designed and built the robot platform from the ground up, including its mechanical structure, leg configuration, sensing layout, and control system integration.

The robot uses adaptive gait control and adjustable body clearance to improve mobility in complex agricultural environments, allowing it to traverse uneven terrain and step over obstacles more effectively.

## My Contributions

- Designed and built the bionic hexapod robot platform
- Developed the mechanical structure and leg configuration
- Integrated sensing and control hardware
- Implemented adaptive gait and clearance-control strategies
- Conducted field and simulation tests for terrain adaptability and stability

## Key Features

- Bionic six-legged robot design
- Adaptive gait control
- Adjustable body clearance
- Lightweight modular structure
- Field-oriented sensing and control system
